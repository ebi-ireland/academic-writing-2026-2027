# 提出前セルフチェック表(CA1 提案書)

> 提出前に採点項目に照らして自分で点検する。全部にチェックが付けば提出。

## 語数(上限厳守・超過は減点)
- [ ] Title 20 語以内 / Keywords 5 個以内
- [ ] Introduction 500 語以内
- [ ] Aims & Objectives 250 語以内
- [ ] Literature Review 1500 語以内
- [ ] Methodology 750 語以内
- [ ] Project Plan / Resources 400 語以内

## Introduction(10%)
- [ ] 背景が具体的(ATT&CK と検知の問題)
- [ ] 意義が明確(盲点 = 侵害がすり抜ける / No.6 を根拠)
- [ ] 問題・全体目標が 1 つに絞れている

## Aims & Objectives(10%)
- [ ] 全体目標が 1 文で明確
- [ ] 各目標が SMART(具体・測定可能・達成可能・関連・期限)
- [ ] 今学期 PoC と次学期を分けてある

## Literature Review(30%)
- [ ] 「並べる」でなく批判的に評価・統合している
- [ ] 最新動向に触れている(No.4)
- [ ] ギャップが 1 段落で明確(オープンソースの再現可能な網羅測定が乏しい)
- [ ] 出典が十分で、査読/権威/灰色のバランスがある
- [ ] すべての主張に出典が付いている

## Methodology(30%)
- [ ] 研究設計が具体的(ラボ・独立/従属変数・測定ループ)
- [ ] 評価指標が明確(3 段階の検知定義・網羅・盲点)
- [ ] ツールを正当化(Wazuh/Sigma/Sysmon/Atomic/Navigator)
- [ ] 倫理・法・環境に触れた(隔離ラボ・責任ある利用・計算コスト)
- [ ] 実現可能性を示した(自分の PC・範囲を締める)
- [ ] 倫理審査の要否を書いた

## Project Plan(10%)
- [ ] 現実的なタイムラインとマイルストーン
- [ ] Gantt か Kanban の図がある
- [ ] 資源(ソフト・ハード・データ)を書いた

## Presentation・Referencing(10%)
- [ ] 文章が明確・簡潔(自分で書いた)
- [ ] 構成・流れが論理的
- [ ] 参照が Harvard UL 形式で統一・誤りなし

## 提出物
- [ ] 指定の Project Proposal Form を使った
- [ ] Student Declaration に署名・日付
- [ ] 別紙 Acknowledgements を用意(acknowledgements-template.md から作成)
- [ ] Blackboard の該当アップロード先に提出
- [ ] 余裕を見て 10/22 に前倒し提出(締切 10/23 23:59)
