# communication/ — AI 利用の記録 / AI-use log

目的: Claude(生成AI)の利用を透明に記録し、課題の Acknowledgements(申告書)の土台にする。

- `jp/ai-use-log.md` — 日本語(自分の理解用)
- `en/ai-use-log.md` — English(指導教員への提出・説明用)

## 方針
- 提案書・報告書の本文はすべて自分で執筆する。AI はアイデア出し・構造・文献確認・自分のノートの清書/翻訳・概念の説明・下書きへの助言にのみ使用する。
- これは「どう使ったか」の**要約ログ**。実際のプロンプト/出力の全文が必要な場合は、セッションのトランスクリプトを書き出して提出物に添付する。

## 注記(重要)
- このリポジトリは **Public**。会話の全文を公開したくない場合は、ここには要約のみを置き、全文は提出時にのみ添付する(またはリポジトリを Private にする)。
- 更新は手動(自動収集はできない)。区切りごとに追記してコミットする。
