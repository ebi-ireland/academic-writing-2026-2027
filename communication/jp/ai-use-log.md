# AI利用ログ(日本語)

ツール: Claude(Anthropic)、Claude Code 経由で利用。

利用範囲 — モジュールのGenAIポリシーで許可された範囲(アイデア出し・ブレストは可、提案書の執筆支援は不可)。
Claude は次に使用: テーマのブレスト、課題資料(Assessment Brief・ルーブリック・スケジュール・テンプレート)の読解、提案書の構造づくり、文献の探索と実在確認、自分の手書きノートの清書・翻訳、概念・用語の説明、自分の下書きへの助言(論理・構成・語数・参照・文法/明瞭さ)。提案書の本文はすべて自分で執筆し、修正もすべて自分で行った。Claude は本文を書いていない。

## セッション(要約)
- 2026-09-16〜09-17: テーマをブレスト。課題資料・ルーブリック・スケジュール・様式を読解。提案書の構造を立てる。
- 2026-09-19〜09-24: テーマ候補を検討。パープルチーム型検知評価(案A)を選択。範囲とツールを確定。自分のPCでラボが成立することを確認。
- 2026-09-28: 実験設計を明確化。文献をWebで実在確認。GitHubリポジトリを設定。
- 2026-10-09〜10-13: CA1素材を整理。ATT&CK・CALDERA論文の手書きCornellノートを清書・翻訳(日/英)。
- 2026-10-21〜10-22: 方法論の5決定を確定。文献の読む地図を作成。CA1をセクション別ファイルに再構成。Introduction と Aims の下書きに助言(助言のみ・修正は自分)。文献リストを整理。
- 2026-10-22〜10-23: 各セクションを自分で英訳し、文法・明瞭さ・語数・採点項目について助言を受けた(修正はすべて自分)。本文中の引用を Harvard(著者・年)形式に変換。各主張と出典を対応づける照合ワークシートを作成し、複数の出典をWebで確認。未引用・弱い文献を削除し、参照URLを1件修正。語数とルーブリックに対する最終確認を実施。提出した本文はすべて自分で執筆。

プロンプト/出力の全文: 主に日本語。代表的なプロンプト(英訳つき)とやり取りの記録は、提出物に付録として添付できる。必要ならセッションのトランスクリプトを書き出す。
