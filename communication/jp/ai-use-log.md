# AI利用ログ(日本語)

ツール: Claude(Anthropic)、Claude Code 経由で利用。

利用範囲 — モジュールのGenAIポリシーで許可された範囲(アイデア出し・ブレストは可、提案書の執筆支援は不可)。
Claude は次に使用: テーマのブレスト、課題資料(Assessment Brief・ルーブリック・スケジュール・テンプレート)の読解、提案書の構造づくり、文献の探索と実在確認、自分の手書きノートの清書・翻訳、概念・用語の説明、自分の下書きへの助言(論理・語数・参照)。提案書の本文は自分で執筆。Claude は本文を書いていない。
